# Smart City Infrastructure and Route Planning

## Overview

This Java application models a smart city's infrastructure
as a weighted graph. Vertices represent city locations,
and edges represent roads with non-negative weights.

## Day 1 — Project Setup

- Created a Maven Java project.
- Implemented the Edge class.
- Implemented the Graph class using an adjacency list.
- Added a sample network with four vertices and five edges.
- Added basic input validation.

## Technology Stack

- Java
- Maven
- IntelliJ IDEA
- Git and GitHub

## How to Run

1. Clone this repository.
2. Open it in IntelliJ IDEA.
3. Load the Maven project.
4. Run smartcity.Main.
